Live Data Flow Example

Scenario: George eats pizza in the kitchen at 11:30 PM

1
VISION Camera detects person + pizza → ArcFace identifies George (0.96) → HSEmotion reads “tired” → Florence-2: “person eating pizza at counter”
2
EVENT VisionEvent published to Redis: {person: "George", activity: "eating", room: "kitchen", mood: "tired", time: "23:30"}
3
BEHAVIOR Matches “Late Night Eating” rule → cooldown OK → escalation level 1 (light humor) → emits BehaviorEvent
4
ORCHESTRATOR Assembles context: tired mood + first reminder today + last conversation 4hrs ago about roasting + goal: “stop eating after 10 PM”
5
CLAUDE API Generates: “Late night pizza mission, huh? You told me you wanted to cut this out. How about I put the kettle on instead?”
6
OUTPUT Piper TTS (200ms) → Home Assistant routes to kitchen speaker → interaction logged to memory
